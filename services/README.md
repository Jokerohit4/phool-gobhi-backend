# Services

- `auth-service/`: Handles authentication and user management.
- `user-service/`: Handles user profile and related data.
- `wallet-service/`: (Deprecated) Was used for wallet management in Node.js. **To be replaced by `payment-wallet-service/` (Java, Spring Boot) for combined wallet and payment logic.**
- `payment-wallet-service/`: (Coming soon) Java Spring Boot service for wallet and payment flows.
