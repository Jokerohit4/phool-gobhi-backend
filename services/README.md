# Services

- `auth-service/`: Authentication, OTP, user/profile management, staff (gobhi) accounts, coaches, trainers.
- `wallet-service/`: Wallet balance, Razorpay top-up orders/webhook, credit/debit, partner payouts.
- `gym-service/`: Gym CRUD, images/docs (Cloudinary), reviews, slot availability, unclaimed gyms.
- `booking-service/`: Booking lifecycle, check-in, FCM push notifications.
- `buddy-service/`: Gym-buddy matchmaking (discovery, swipes, matches, chat).
- `challenge-service/`: Gamification (badges, streaks, coins, challenges).
- `health-service/`: Health & activity (exercise records, routines, workout sessions, biomarkers).
